CONTACT MANAGER - HOW TO RUN (VS Code + Live Server)

You need BOTH of these running at the same time:

1. START THE BACKEND (saves contacts in SQLite)
   - File > Open Folder > select this "contact-management" folder
   - Open app.py and press F5   (or type: python app.py in the terminal)
   - Wait for: Running on http://127.0.0.1:5000

2. OPEN THE PAGE WITH LIVE SERVER
   - Install the "Live Server" extension (Ritwick Dey) once
   - Right-click templates/index.html > Open with Live Server

Shortcut: you can also just visit http://127.0.0.1:5000/ without Live Server.
